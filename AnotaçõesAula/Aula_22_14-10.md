3) **HASH**: estrutura de dados mais eficiente, ideal para estruturas grandes
    -  função de espalhamento, ou seja, um dado é armazenado ou pequisado na estrutura via um código de endereçamento conceitos
    - não é utilizado para ordenação, pois mantém a sequencia de inserção
    - tabela hash não tem índice, ou seja, o for com int i = 0, não vai funcionar
    - conceitos:

        - **tabela hash:** estrutura de dados que armazena os dados
        - **função hash:** cálculo de endereçamento para armazenar e buscar elementos na estrutura - O(1) - complexidade baixa 
        - menor esforço
        - **Ordenação**: esforço é calculado: qtde de comparações + qtde de trocas
        - **Pesquisa**: esforço é calculado: qtde comparações, tipos: sequencial, binário,digital.

    - **tipos de tratamento de colisões:**
        - listas encadeadas
        - tipos de hash
            - open addressing ou closed hashing
    
    - **tipos de hash e a difirenças**
       - **HashMap:** Armazena dados em pares de chave e valor (key-value). Não permite chaves duplicadas e não é sincronizado.

      - **HashSet:** Armazena elementos únicos, sem duplicatas. Não trabalha com pares de chave e valor.

      - **Hashtable:** Armazena dados em pares de chave e valor, assim como o HashMap, mas é sincronizado, sendo mais seguro para acesso simultâneo entre threads, embora geralmente seja mais lento. 

    - Set: configuração,conjunto
    - Map: dicionario
