- **String:** É imutável. Toda vez que você altera uma String (como usar o operador +), o Java cria um objeto totalmente novo na memória em vez de modificar o original.
- **StringBuilder:** É mutável e focado em performance. Permite modificar o texto (usando .append()) no mesmo espaço de memória. Como não é sincronizado para múltiplas threads, opera de forma muito rápida.
- **StringBuffer:** Funciona exatamente como o StringBuilder, mas seus métodos são sincronizados (thread-safe). Isso evita conflitos se várias partes do programa mexerem no texto ao mesmo tempo, mas traz uma perda de desempenho por conta desse bloqueio de segurança
