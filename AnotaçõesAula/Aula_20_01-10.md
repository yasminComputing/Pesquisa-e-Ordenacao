- `Pesquisa Binária`: um bom método, mas **precisa estar ordenado**. Se tiver uma estrutura muito grande.

```java
    public static boolean pesquisaBinaria(int numero,ArrayList<Integer> lista){
        int ini = 0;
        int fim = lista.size() - 1;
        int meio;

        long qtdComparacoes = 0;

        do{
            meio = (int)(ini+fim)/2;
            qtdComparacoes++;
            if(numero == lista.get(meio)){
                return true;
            }
            if(numero < lista.get(meio)){
                fim = meio - 1;
            }else{
                ini = meio + 1;
            }
        }while(ini >= fim);
        return false;
}
```
