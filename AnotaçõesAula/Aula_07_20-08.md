## Desafio 
CLASSE PROCESSO - int id, Date data -> ordenar primeiro por id e depois data e depois tentar usando as duas chaves 

1 ) COMO ORDENAR UMA LISTA POR ALGUMA CHAVE DO OBJETO

2 ) COMO ORDENAR, POR EXEMPLO,POR DATA E ID NA 2º CHAVE

Código do desafio: ([CÓDIGO](https://github.com/yasminComputing/Pesquisa-e-Ordenacao/tree/main/CodigoAulaUsandoPente_20.08)). 
```csharp
 lista[i].id > lista[i + dist].id →  é verificado o ID. 
    Se o ID do elemento atual for maior que o ID do elemento que está sendo comparado, os elementos são trocados.

 lista[i].Equals(lista[i + dist]) → o método Equals() verifica se os dois objetos possuem o mesmo ID.
    Se os IDs forem iguais, é usado a segunda chave de ordenação, que é a data.

 lista[i].data > lista[i + dist].data →  comparada a data dos elementos.
    Se a data do elemento atual for maior que a data do elemento que está sendo comparado, os elementos são trocados
```
