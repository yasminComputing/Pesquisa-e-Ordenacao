# Complexidade

O significado da palavra **complexidade** na computação está relacionado ao **esforço computacional** necessário para a execução de um algoritmo.

### Observação

> Quanto maior o esforço computacional realizado pelo algoritmo, menor será sua eficiência.

# Algoritmos de Ordenação

- **Sort:** significa ordenar.

- **Bubble Sort (Ordenação por Bolha):** algoritmo simples de implementar, porém possui alta complexidade.

- **Selection Sort (Ordenação por Seleção):** realiza a seleção dos menores ou maiores elementos para organizar a lista.

- **Insertion Sort (Ordenação por Inserção):** organiza os elementos inserindo cada item em sua posição correta.

- **Cocktail Sort (Agitação):** variação do Bubble Sort que realiza a ordenação nos dois sentidos.

- **Comb Sort (Ordenação por Pente):** melhora o Bubble Sort utilizando comparações com maiores distâncias entre os elementos, reduzindo a complexidade.

- **Shell Sort:** utiliza uma sequência de intervalos (gaps) para realizar a ordenação de forma mais eficiente.

- **Radix Sort:** algoritmo que realiza a ordenação utilizando os dígitos dos elementos.

- **Bucket Sort:** distribui os elementos em grupos (baldes) para facilitar a ordenação.

- **Merge Sort:** algoritmo baseado na técnica de divisão e conquista, possui baixa complexidade.

- **Quick Sort:** algoritmo eficiente baseado na escolha de um pivô para dividir os elementos.
