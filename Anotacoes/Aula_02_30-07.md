# Conceitos Inicias
  - Ordenar: organizar uma estrutura (lista ou vetor) a partir de um ou mais índices.

      - Por que ordenar?
        
         `para otimizar a busca ou pesquisa.`
        
  - Pesquisar: localizar ou buscar um dado dentro de uma estrutura via alguma chave.
  - Search/find: buscar/localizar/pesquisar 
  - Recuperar: localizar ou buscar dados com relevância (semântica ou significado)
  - Complexidade de um algoritmo: é o esforço computacional de um algoritmo, ou seja, quanto de recurso ele aloca para realizar
sua ou suas tarefas.

    - Alta complexidade: mais esforço
    
    - Baixa complexidade: menos esforço
    
    - Notação Big 0
        - O (n!) - fatorial | Maior complexidade
        - O (n^x) - exponencial 
        - O (log n + n)
        - O (n) - linear
        - O (log n) logaritmo | maior complexidade
    - Estabilidade: quanto a estrutura é desordenada até chegar na ordenação, exemplo o `Bubble Srot` é estável. Já o `Comb Sort`   que é instável.
