# Atividade 
1) pesquisar na literatura, internet ou IA Generativa sobre os métodos de ordenação e categoriza-los em:
    - algoritmo de memória interna ou memória externa
    - estabilidade (estável ou instável)
    - complexidade
    - porções de ordenação
      
Os seguintes métodos de ordenação:

    - bolha (bubble sort)
        - memória interna
        - estável
        - O(nˆ2)
        - porção ordenada: final

    - seleção (selection sort)
        - memória interna
        - instável
        - O(nˆ2)
        - porção ordenada: início

    - inserção (inserction sort)
        - memória interna
        - estável
        - O(nˆ2)
        - porção ordenada: início

     Seguindo exatamente o mesmo esquema:

    - pente (Comb Sort)
        - memória interna
        - instável
        - O(n²) (pior caso)  
        - porção ordenada: final

    - agitação (Shake Sort / Cocktail Sort)
        - memória interna
        - estável
        - O(n²)
        - porção ordenada: início e final

      - shellsort
        -  memória interna
        - instável
        - O(n²) (pior caso)
        - porção ordenada: por intervalos (gaps)

      - bucketsort
        -  memória interna
        - estável
        - O(n + k) (caso médio)
        - porção ordenada: baldes (buckets)

      - radix sort
        - memória interna
        - estável
        -  O(d · (n + k))
        - porção ordenada: por dígitos

      - heapsort
         - memória interna 
         - instável
         - O(n log n)
         - porção ordenada: final
 

      - mergesort
        -  memória externa
        - estável
        - O(n log n)
        - porção ordenada: subvetores

        - quicksort
          - memória interna
          - instável
          - O(n log n) (caso médio) / O(n²) (pior caso)
          - porção ordenada: em torno do pivô


2) Método: que recebe uma lista e retorna **true** se está ordenado, ou **false**, caso contrario. 

# Comentários
 -  **eficiente versus eficaz**
        - ambos atingem objetivos
        - só que eficaz tem relação com tempo

  - **qual o melhor algoritmo de ordenação?**
        Depende:
            - do tamanho da estrutura
            - do quanto já está ordenado


   - **Cenários de um processo de ordenação**
        - pior caso
            bolha - lista ordenada decrescente e se desejar ordenar crescente
          
            seleção - lista ordenada
          
            inserção - lista ordenada decrescente e se desejar ordenar crescente
